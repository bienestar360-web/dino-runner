Ranking de Dino Runner: cómo escalar posiciones y llegar al top 3

El ranking no mide "quién es mejor jugando". Mide quién resistió más tiempo antes del impacto. Esa distinción no es narrativa: es técnica. El ranking solo cuenta el score total, no distingue entre partidas con mucha carne y partidas con poca. Esta guía explica cómo funciona, cuándo se guarda, cómo se lee el top 3 y qué estrategias funcionan de verdad para subir.

Cómo funciona el ranking

El ranking se gestiona con Supabase y almacena el top 3 global. Cada partida que entra en el corte se registra con el score y el alias del jugador. El ranking no es una tabla infinita: es un top 3, y solo el top 3 se conserva.

Eso tiene una consecuencia práctica: no compites contra miles de jugadores, compites contra la tercera mejor puntuación registrada. Si el top 3 está en 6,200 puntos, necesitas superar 6,200 para entrar. No hay premio por quedar cuarto.

Cuándo se guarda tu puntuación

La puntuación se guarda al morir, no durante la partida. El flujo es:

1. El dino choca con un obstáculo.

2. Aparece la pantalla de Game Over.

3. El juego compara tu score con el top 3 actual.

4. Si tu score supera al tercero, se registra con tu alias.

5. Si no lo supera, la partida se descarta.

No hay guardado parcial ni autoguardado. Si cierras la pestaña antes del Game Over, la partida se pierde. Esto es relevante en móvil: si el navegador mata la pestaña por falta de memoria, la partida no se registra aunque hayas hecho 8,000 puntos.

Top 3 y cómo verlo

El top 3 se muestra en la pantalla de Game Over, debajo de tu score. La pantalla incluye:

  • Tu puntuación final.
  • Tu posición (o "fuera del top 3").
  • El top 3 con alias y score.
  • El botón de reinicio.

Captura de referencia: pantalla de Game Over con score, posición y top 3 visible. El jugador puede reiniciar sin salir de la pantalla.

Si el ranking está vacío (sitio nuevo o base de datos reseteada), la pantalla muestra el top 3 vacío y cualquier partida entra en el primer puesto. No hay un mínimo de puntos para entrar: la primera partida siempre entra.

Estrategias para subir

Las estrategias que funcionan en partidas reales se reducen a cinco reglas:

1. Supera los 3,000 puntos antes de intentar el top 3. El corte real depende de las puntuaciones que haya en el ranking en ese momento.

2. No arriesgues por carne fuera de tu ruta. Un filete vale 50 puntos, y una colisión puede costarte una vida o la partida completa.

3. Juega en el mismo dispositivo. El alias se guarda en `localStorage`/`sessionStorage`. Cambiar de dispositivo cambia de alias, y el ranking no vincula cuentas.

4. Repite el mismo patrón de esquivar. El ranking premia la consistencia, no la suerte. Si tu mejor partida fue 4,800, intenta replicar las decisiones de esa partida, no improvisar.

5. Acepta que el corte sube. Si el top 3 está en 7,000, necesitas 7,001. No hay atajo: la única forma de subir es jugar más y mejor.

Para el desglose de puntos que necesitas para 5,000, consulta el sistema de puntuación. Para la estrategia, consulta la guía de estrategia avanzada.

Por qué no aparece tu alias

Si tu puntuación entra en el top 3 pero el alias no aparece, las causas habituales son:

  • El alias no se guardó: `localStorage` está bloqueado (modo incógnito, cookies desactivadas). Solución: jugar en ventana normal.
  • El navegador borró el storage: limpieza automática, cierre forzado. Solución: no cerrar la pestaña antes del Game Over.
  • El ranking no recibió la escritura: error de red en el momento del Game Over. Solución: repetir la partida; el score no se recupera.
  • El alias es genérico: el juego asigna un alias por defecto si no defines uno. Solución: revisar la guía de alias y nombres.

Para ver técnicas de los mejores jugadores reales, consulta el artículo de mejores jugadores. Para volver a los fundamentos, consulta la guía para principiantes.

El ranking no promete top 3 fácil. Promete que, si resistes más que el tercero, entras. Nada más.
